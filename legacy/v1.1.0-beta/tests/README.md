# 验证脚本

这些脚本用 [jsdom](https://github.com/jsdom/jsdom) 模拟 B 站页面与浏览器扩展 API，用来验证扩展的核心行为。
**它们只用于开发自测，不参与扩展运行，也不是加载扩展所必需的。**

## 运行

```bash
cd tests
npm install          # 安装 jsdom
npm test             # 运行全部验证
```

或单独运行：

```bash
node test-content.js      # 内容脚本：屏蔽逻辑、分区识别、悬停展示、面板拖动、深色模式
node test-ui.js           # 扩展弹窗与完整设置页的交互
node test-background.js   # 后台 Service Worker：统计、徽标、默认配置
```

## 覆盖内容

| 脚本 | 校验点 |
| --- | --- |
| `test-content.js` | 59 项：面板挂载/Shadow DOM 隔离、关键词命中、**整体遮蔽** 文案与结构、**鼠标悬停自动展示**、**完全隐藏**、**分区卡片级屏蔽**（已知类名 + 未知类名通用识别）、**分区板块级屏蔽**（整行 + 楼层标题 + 顶部轮播横幅）、**顶栏导航不被误伤**、解除屏蔽、正则与大小写、UP 主匹配、MutationObserver 捕获滚动新增卡片、**悬浮按钮拖动与位置记忆/重置**、总开关、深色模式识别 |
| `test-ui.js` | 41 项：弹窗与设置页的渲染、屏蔽词增删与批量去重、模式/主题/正则开关保存、**分区卡片/整行两个开关互相独立**、整行板块开关、**悬停展示开关**、预览同步、重置悬浮按钮位置、恢复默认 |
| `test-background.js` | 18 项：默认配置写入、屏蔽计数累加、徽标数字与颜色、`999+` 截断、统计查询与重置、安装事件补齐默认值 |

合计 **118 项**。

> 注意 1：浏览器里 `DOMContentLoaded` 只会触发一次；如果你的测试里手动派发该事件，会让监听器重复绑定，
> 从而出现「开关点了没反应」的假象。页面脚本已改用 `ready()` 助手（`readyState !== 'loading'` 时立即执行），
> 测试中无需手动派发。
>
> 注意 2：内容脚本测试用的模拟 DOM 结构取自 **2025 年 B 站首页的真实结构**
> （`.feed-card > .bili-feed-card > .bili-video-card / .bili-live-card`、`.carousel-area` 轮播横幅、
> `.floor-*` 楼层区块、顶栏 `.channel-link__right` 导航入口），因此能覆盖真实的误伤场景。
